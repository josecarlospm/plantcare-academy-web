## Development

```bash
npm install
npm start
```

## Verify

```bash
npm test
npm run build
```

## Design notes (SF-10)

First viewport is a single brand-led composition: product name, one headline, one supporting line, one CTA group, and a full-bleed botanical plane. No hero stats, emoji marks, or pill clusters. Course cards are reserved for interactive catalog selection.
